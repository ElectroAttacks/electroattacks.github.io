### 📜 My Developer Journey

#### 🚀 How It All Began: Batch Scripts & Early Projects
Like many, my journey started during my youth with simple `.bat` scripts. As my ideas grew, so did the complexity of my scripts:
- **Network Scanner:** A multi-terminal IP scanner and ping tool (which Windows Defender proudly flagged as a virus because it launched dozens of terminal windows at once to log replies).
- **Minecraft Server Manager:** A CLI-based tool with a configuration menu, launch tracker, and auto-restart function on server crashes.

#### 🔄 Stepping Up: VB.NET & WinForms
Looking for a proper development environment, I transitioned to **VB.NET (.NET Framework)**. 
- Rebuilt my network tools with added features: connection scoring, IP scanning, traceroute, and a brand-new **GUI for the Minecraft Server Manager**.

#### 🎯 Embracing C# & WPF
To align with industry standards, I translated my projects to **C#** to master the syntax. Once I hit the limitations of WinForms, I stepped into **WPF**.
- Learning markup languages and UI design guides was overwhelming at first, but after a few breaks and tutorials, core patterns like **MVVM** and **SRP** clicked. 
- Thanks to **Tim Corey**, concepts like validation, async/await, and parallelism became second nature.

#### 🏗️ Modern Architecture & Clean Code
Inspired by **Nick Chapsas** (tutorials, benchmarks, and best practices), I transformed my coding style to adopt:
- **Clean Architecture**
- **CQRS & Mediator Pattern**
- **Facets & Design Patterns**

This phase involved deep dives, resetting my mental model, and countless debates with AI on where the *Single Responsibility Principle* actually begins and ends (turns out I defined responsibilities a bit *too* broadly early on!). It was a complex path, but raising my quality standards was 100% worth it.
